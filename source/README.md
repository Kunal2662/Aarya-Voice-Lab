# `source/` — Private Source Material

This directory is the designated (future) location for the **31 original
recordings** and any material derived directly from them. It is currently
**empty and intentionally left that way** — Phase 0 does not access, copy,
inspect, or process the recordings in any way.

## Rules (non-negotiable)

1. **Originals are immutable.** Once introduced in an approved Voice
   Dataset phase, original recordings must never be edited, re-encoded,
   overwritten, or renamed in place. Any transformation produces a new
   *derived* artifact elsewhere in the pipeline (see
   `docs/DATASET_PIPELINE.md`); the original file is never touched.
2. **Originals must remain outside Git.** Everything under `source/`
   (except this README and other documentation) is excluded via the
   root `.gitignore`. No original or derived audio, transcript-with-audio,
   embedding, or fingerprint may be committed.
3. **Originals must never be uploaded automatically.** No script, CLI
   command, CI job, or dependency in this repository may transmit files
   from `source/` to a network destination (cloud storage, API, logging
   service, telemetry, etc.) without a explicit, separate, human-approved
   action taken outside of an automated pipeline run.
4. **Processing requires explicit approval.** Phase 0 defines the
   architecture, schemas, and safety policy for the future pipeline
   (diarization, transcription, extraction, etc.) but implements none of
   it against real recordings. Real processing begins only in an
   explicitly approved later phase.
5. **Private datasets must remain local/protected.** Any dataset derived
   from these recordings (segments, transcripts, embeddings, verified
   subsets) is private-voice material and inherits the same protections:
   local storage only, never committed, access restricted to authorized
   operators.

## What belongs here (later phases only)

- Original recording files (read-only once ingested)
- A local (git-ignored) inventory/index describing the files present,
  generated by tooling — not the audio itself

## What does NOT belong here

- Anything copied into Git history
- Anything uploaded to a third-party service
- Processed, trimmed, denoised, or re-encoded copies (those belong in a
  separate, equally protected `datasets/` working area, also git-ignored)

See also: `docs/PRIVACY.md`, `docs/SECURITY.md`, `docs/DATASET_PIPELINE.md`.
