# Install torch FIRST from the wheel index matching your driver -- this is

# intelligible speech, see docs/INDICF5_INSTALLER.md):
#   pip install torch==2.13.0 torchaudio==2.11.0 --index-url https://download.pytorch.org/whl/cu126
#   pip install torch==2.13.0 torchaudio==2.11.0 --index-url https://download.pytorch.org/whl/cpu
# then install this file.
#
# Do NOT `pip install f5-tts`. IndicF5's checkpoint was trained against an
# older F5-TTS than what PyPI's f5-tts package ships today -- confirmed
# this project's own real diagnostic session: loading succeeds against the
# PyPI package (parameter shapes match), but generation produces
# unintelligible audio (a newer default, DiT.text_mask_padding=True, added
# after this checkpoint existed, among other accumulated differences).
# The working implementation is vendored directly in this repository at
# scripts/ml_workers/vendor/indicf5_f5tts/ (AI4Bharat's own bundled F5-TTS
# source, not the PyPI package) -- it needs f5-tts's underlying
# dependencies below, but never f5-tts itself. See that package's module
# docstrings and docs/INDICF5_INSTALLER.md for the full provenance.
#
# Model access: ai4bharat/IndicF5 is a GATED HuggingFace repository --
# confirmed empirically (anonymous download returns 401 GatedRepoError).
# A HuggingFace account with the model's access request approved, and a
# valid token, are required before the checkpoint can be downloaded. No
# credential is stored by this project outside huggingface_hub's own
# token cache. See docs/INDICF5_INSTALLER.md.
#
# trust_remote_code: NOT used anywhere in this project's IndicF5 path.
# The model is built directly from the vendored library code above and
# loads only tensor weights via safetensors (incapable of executing
# code) -- a deliberately different, safer path than the
# transformers.AutoModel.from_pretrained(trust_remote_code=True) route
# IndicF5's own published model card documents.
#
# Every version below is pinned EXACTLY to what was verified end-to-end
# (checkpoint loads, real CUDA generation, human-confirmed intelligible
# speech) -- silent version drift is the failure mode this project's own
# compatibility audit (docs/COMPATIBILITY.md) warns against repeatedly.
